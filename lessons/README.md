## 如何运行

### 安装 Go
确保你已经安装了 Go 语言环境（1.16 或更高版本）：
```bash
go version
```

### 运行单节课
```bash
# 进入课程目录
cd e:\GO\go-chain\lessons

# 运行第一课（-tags 与文件名中的课程编号对应）
go run -tags lesson01 lesson_01_block.go

# 运行第四课
go run -tags lesson04 lesson_04_mining.go

# 依此类推：lesson02 … lesson09
```

### 运行完整版
```bash
go run -tags lesson09 lesson_09_complete.go
```

## 课程内容概览

### 第一课：区块结构
学习区块链中最基本的数据单元 - "区块"，理解：
- 区块包含哪些信息
- 什么是创世区块
- 区块如何通过 PreviousHash 连接

### 第二课：哈希计算
理解哈希的概念和作用：
- 什么是哈希
- SHA-256 哈希算法
- 哈希的唯一性和确定性
- 改变数据会改变哈希

### 第三课：区块链结构
将区块组织成链：
- 区块链的数据结构
- 添加新区块的流程
- 验证区块链完整性
- 检测数据篡改

### 第四课：挖矿与工作量证明
理解区块链的共识机制：
- 什么是挖矿
- 工作量证明原理
- Nonce 的作用
- 难度与计算量的关系

### 第五课：交易系统
实现完整的交易功能：
- 交易的数据结构
- 待确认交易池（Mempool）
- 余额验证
- 挖矿奖励

### 第六课：数字签名与钱包
学习加密和身份认证：
- 公私钥加密
- 数字签名原理
- 钱包的创建和使用
- 交易的签名和验证

### 第七课：智能合约
实现可编程的区块链：
- 智能合约的概念
- 合约注册表
- 计数器合约
- 代币合约（简化版 ERC-20）
- 投票合约

### 第八课：P2P 网络
理解节点间通信：
- P2P 网络架构
- 节点发现
- 消息广播
- 区块链同步

### 第九课：完整系统整合
将所有功能整合：
- 完整的区块链演示
- 钱包创建和交易
- 挖矿确认
- 智能合约调用
- P2P 节点连接

## 常见问题

**Q: 我没有 Go 基础，能学吗？**
A: 本课程的代码注释非常详细，即使没有 Go 基础也能理解概念。如果想深入，建议先花 2-3 小时了解 Go 基础语法。

**Q: 学完能自己发币吗？**
A: 可以！本课程包含了代币合约的基础知识。要发币还需要学习具体的平台（如以太坊的 ERC-20）。

**Q: 这些代码可以直接用于生产环境吗？**
A: 不可以。这是一个教学演示，生产环境的区块链需要更严格的安全性、性能优化和边界检查。

**Q: 挖矿真的能赚钱吗？**
A: 个人挖矿比特币已经很难盈利了。你可以考虑挖其他币或加入矿池，但要做好功课。
